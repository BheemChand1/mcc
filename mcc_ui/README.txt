MCC Command Center UI
=====================
Pure HTML, CSS and JavaScript frontend recreation of the supplied dashboard image.

Files:
- index.html
- styles.css
- script.js
- assets/railway-logo.png

Features:
- Dark theme matching the supplied dashboard
- Light theme toggle (sun/moon button in the top-right toolbar)
- Responsive/collapsible sidebar
- Fullscreen button
- Live Vande Bharat countdown
- Live clock in bottom sync status
- No framework/backend required

Open index.html in a modern browser.
